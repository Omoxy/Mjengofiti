# Mjengofiti — Geospatial Data Manifests and Provenance

This directory contains data acquisition manifests, licences, cryptographic checksums, and schema mappings for Nairobi County building intelligence. Boundary records are classified by their actual source provenance; the current county layer is a verified alternative, not an official statutory boundary.
